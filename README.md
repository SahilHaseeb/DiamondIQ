# 💎 DiamondIQ — Diamond Price Prediction System

**An End-to-End Machine Learning Project for Predicting Diamond Prices**

DiamondIQ is a Machine Learning-based web application that predicts the estimated price of a diamond based on its physical characteristics and quality attributes.

The project combines Data Science, Machine Learning, Data Visualization, Web Development, Flask, and SQLite Database Integration into one complete application.

---

## 📌 1. Project Overview

The price of a diamond depends on several factors, including its carat weight, cut quality, color, clarity, and physical dimensions.

Manually estimating diamond prices can be difficult because multiple characteristics influence the final price.

DiamondIQ solves this problem by using Machine Learning algorithms trained on historical diamond data.

Users can enter diamond specifications through a web interface and receive an estimated price generated by the trained Random Forest model.

The application also stores prediction records in an SQLite database and displays previous predictions in a Prediction History section.

### Main Objectives

- Analyze diamond data using Python.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Create meaningful data visualizations.
- Apply and compare multiple Machine Learning algorithms.
- Select the best-performing model.
- Build a user-friendly web application.
- Integrate the trained model with Flask.
- Store prediction history using SQLite.

## 📂 3. Dataset Description

The project uses a diamond dataset containing information about diamond characteristics and their prices.

### Original Dataset

- Total records: 53,940
- Original columns: 11
- Target variable: `price`

### Dataset Features

| Feature | Description |
|---|---|
| carat | Weight of the diamond |
| cut | Quality of diamond cutting |
| color | Diamond color grade |
| clarity | Diamond clarity grade |
| depth | Total depth percentage |
| table | Width of the top surface relative to its widest point |
| x | Length in millimeters |
| y | Width in millimeters |
| z | Depth in millimeters |
| price | Diamond price (target variable) |

The original dataset also contained an unnecessary index column named `Unnamed: 0`, which was removed during cleaning.

## 🧹 4. Data Cleaning and Preprocessing

Data cleaning was performed to improve data quality before training Machine Learning models.

### Step 1: Dataset Inspection

- Loaded the original dataset using Pandas.
- Checked dataset shape and column names.
- Inspected data types.
- Checked missing values.
- Examined descriptive statistics.

Original dataset shape:

`(53,940, 11)`

### Step 2: Remove Unnecessary Column

The `Unnamed: 0` column was removed because it was only an index and did not provide useful information for price prediction.

### Step 3: Handle Zero Dimensions

The physical dimensions of a diamond should not be zero.

Records containing zero values in the `x`, `y`, or `z` dimensions were identified and removed.

- Records removed: 20

### Step 4: Remove Duplicate Records

Duplicate records were identified and removed to avoid unnecessary repeated observations.

- Duplicate records removed: 145

### Step 5: Identify Outliers

Potential outliers were investigated in the following numerical features:

- carat
- depth
- table
- price
- x
- y
- z

Outliers were examined using statistical analysis and visualizations.

### Step 6: Remove Extreme Dimension Errors

Three records containing extreme and suspicious physical dimension values were removed.

### Final Cleaned Dataset

| Description | Records |
|---|---:|
| Original records | 53,940 |
| Zero-dimension records removed | 20 |
| Duplicate records removed | 145 |
| Extreme dimension records removed | 3 |
| Final cleaned records | 53,772 |

Final dataset shape:

`(53,772, 10)`

No missing values remained in the cleaned dataset.

## ⚙️ 5. Feature Engineering

Feature engineering was performed to create an additional feature that could help the Machine Learning model understand the physical size of a diamond.

### Diamond Volume

A new feature named `volume` was created using the three physical dimensions.

Formula:

`Volume = x × y × z`

Where:

- x = Length
- y = Width
- z = Depth

This feature represents the approximate physical volume of the diamond.

The new feature was added to the dataset before model training.

## 🤖 7. Machine Learning Models

Four Machine Learning algorithms were trained and evaluated for diamond price prediction.

The target variable was:

`price`

The problem was treated as a **Supervised Machine Learning Regression Task** because the model predicts a continuous numerical value.

### Models Implemented

**1. Linear Regression**

A basic regression algorithm used to establish a baseline for price prediction.

**2. Decision Tree Regressor**

A tree-based algorithm that learns decision rules from diamond features.

**3. Random Forest Regressor**

An ensemble learning algorithm that combines multiple decision trees to improve prediction performance and reduce individual tree errors.

**4. Gradient Boosting Regressor**

An ensemble algorithm that builds decision trees sequentially, with each new tree attempting to improve previous predictions.

---

## 📈 8. Model Evaluation and Comparison

The models were evaluated using three standard regression metrics.

### Evaluation Metrics

**Mean Absolute Error (MAE)**

Measures the average absolute difference between actual and predicted prices.

**Root Mean Squared Error (RMSE)**

Measures prediction error while giving greater weight to larger errors.

**R² Score**

Measures how well the model explains the variation in the target variable.

### Model Performance Results

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Linear Regression | 715.96 | 1112.86 | 0.9203 |
| Decision Tree | 356.87 | 737.61 | 0.9650 |
| Random Forest | 268.79 | 537.04 | 0.9814 |
| Gradient Boosting | 402.81 | 715.96 | 0.9670 |

### Best Performing Model: Random Forest

Random Forest achieved the best results among the four tested models.

- MAE: 268.79
- RMSE: 537.04
- R² Score: 0.9814

The R² score of 0.9814 indicates that the model explains approximately 98.14% of the variation in the target variable on the evaluation dataset.

Therefore, Random Forest was selected as the final prediction model.

## 🔍 9. Feature Importance Analysis

Feature importance analysis was performed to understand which features contributed most to the Random Forest model's predictions.

The analysis showed that diamond volume was the most influential feature, followed by the physical dimension `y` and other diamond characteristics.

This helped explain how the trained model uses input features when estimating diamond prices.

## 💾 10. Model Saving

After selecting Random Forest, the trained model and preprocessing pipeline were saved using Joblib.

Saved files:

- `random_forest_model.pkl`
- `preprocessor.pkl`

The preprocessing pipeline is saved separately so that new user inputs receive the same transformations used during model training.

This allows the Flask backend to load and use the trained model without training it again for every prediction.

## 🌐 11. Web Application Development

A web application was developed to make the Machine Learning model accessible through a user-friendly interface.

### Frontend

The frontend was developed using:

- HTML
- CSS
- JavaScript

The website includes:

- Home section
- Diamond Prediction section
- Prediction Result display
- Prediction History section
- About section
- Model Performance section

### Backend

Flask was used to connect the frontend with the saved Machine Learning model.

The backend:

1. Receives diamond information from the frontend.
2. Validates the input values.
3. Calculates diamond volume.
4. Preprocesses the input data.
5. Loads the trained Random Forest model.
6. Predicts the estimated diamond price.
7. Saves the prediction in SQLite.
8. Returns the result to JavaScript.

### Prediction Input Features

Users provide the following information:

- Carat
- Cut
- Color
- Clarity
- Depth
- Table
- X dimension
- Y dimension
- Z dimension

The application returns the estimated diamond price in USD.

## 🗄️ 12. Database Integration

SQLite was integrated to store prediction history.

Whenever a user successfully predicts a diamond price, the input features, predicted price, and creation timestamp are saved in the database.

### Database Table: `predictions`

| Column | Description |
|---|---|
| id | Unique prediction ID |
| carat | Diamond weight |
| cut | Diamond cut grade |
| color | Diamond color grade |
| clarity | Diamond clarity grade |
| depth | Diamond depth |
| table_value | Diamond table percentage |
| x | Length |
| y | Width |
| z | Depth dimension |
| predicted_price | Model prediction |
| created_at | Prediction timestamp |

### Prediction History Features

The website retrieves saved predictions through a Flask API.

It displays:

- Total number of predictions.
- Average predicted price.
- Previous prediction records.
- Prediction dates and times.

This makes it possible to review earlier predictions without losing them when navigating between website sections.
